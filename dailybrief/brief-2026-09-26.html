AI / Coding Agents

NewGitHub Agentic Autofix now uses Copilot Memory

GitHub says Agentic Autofix can now read Copilot Memory while fixing security alerts and can save useful patterns from successful fixes back into repository memory. Those memories can also be reused by Copilot code review and the cloud coding agent; the integration is currently in public preview. 这让 repository memory 从单纯的“上下文便利”变成跨 agent 共享的 durable learning layer，也意味着 memory 的 provenance、过期和错误传播会越来越像正式工程状态，而不是聊天历史。

NewAnthropic opens plugin submission for Claude

Anthropic’s new submission flow lets developers publish remote MCP connectors or package MCP servers and skills together as Claude plugins. The process includes automated validation and safety scanning, review tracking, publishing controls, and post-launch discovery/install analytics; Claude Code plugins can also bundle commands, hooks, agents and related development integrations. 对 MCP/Skill builders 来说，问题开始从“怎么接一个 tool”转向 capability 的 packaging、versioning、review、distribution 和 measurement。

NewMicrosoft introduces Copilot Home, Code and Autopilot

Microsoft is reorganizing Copilot around three modes: Home brings conversational work together, Code builds apps, dashboards and automations from natural language on a managed sandboxed runtime, and Autopilot is a persistent cloud agent with its own identity, memory, computer and workspace that can continue work across time. Home and Code are heading into Frontier availability, while Autopilot is expanding private preview. 关键变化是 persistent agents 被当作可治理的 tenant resource，而不只是“更长的 chat session”。
