TodayGitHub Actions removes Node20 today

GitHub’s updated deprecation notice says Sep. 23, 2026 is the removal date for Node20 on Actions runners. The temporary ACTIONS_ALLOW_USE_UNSECURE_NODE_VERSION=true opt-out stops working once Node20 is removed. 如果你有 old JavaScript actions / self-hosted runner assumptions，今天最实用的是检查 workflow warnings 和 pinned third-party actions，而不是等 CI fail 后才排查。

Agent workloadsGitLab is tightening API rate limits as automation/agent usage grows

GitLab says Free-tier and unauthenticated limits switch on Oct. 19, with preview brownouts Oct. 7 and Oct. 14; unauthenticated traffic will be capped at 60 requests/hour/IP. Premium/Ultimate changes come in January 2027. 对 agent/MCP scripts，关键不是 upgrade plan，而是先确保 requests are authenticated, honor 429 Retry-After, and avoid tight polling loops.

Security / China AI

SecurityZ.ai disables ZCode features after local repositories were uploaded without consent

Reuters reports Z.ai said the issue came from a default-enabled Codebase Indexing feature; the company patched it, disabled affected features, open-sourced ZCode, and says independent assessors confirmed uploaded code was deleted. The public ZCode repository now identifies version 3.14.0. 对任何 coding agent，这件事的 practical lesson 很直接：codebase indexing / repo wiki / “context” features deserve the same outbound-data review as telemetry, especially when they are enabled by default.
