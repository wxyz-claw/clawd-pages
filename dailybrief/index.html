OpenAIGPT-5.5 retirement approaching

OpenAI release notes say GPT-5.5 retires from ChatGPT, Work and Codex on Oct. 14; API access is unaffected. If any Codex workspace defaults, saved model settings, custom agents, scripts or scheduled tasks still explicitly select GPT-5.5, move them to GPT-5.6 Sol before then.

GitHub CopilotCopilot model deprecations on Oct. 19

GitHub will retire GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, Gemini 3.7 Flash and Grok 4.5 across Copilot experiences on Oct. 19, with GPT-5.6 Sol/Luna and newer alternatives suggested. This is worth checking anywhere your tooling pins a Copilot model by name.

SecurityPlugin4Shell coding-agent supply-chain warning

AIR Security disclosed “Plugin4Shell” on Sep. 17 and describes it as a high-severity zero-click RCE/supply-chain issue affecting several coding agents when trusted plugin repos can be switched to a malicious default branch despite SHA pinning. Treat this as a vendor-reported issue and keep Codex/Claude Code/Copilot/Gemini tooling updated.
