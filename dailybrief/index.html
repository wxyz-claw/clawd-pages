New announcementBloomberg launches Enterprise MCP for Data License Plus

Source published Sep. 29, 2026 · First seen in this briefing Sep. 29, 2026

Bloomberg’s new Enterprise MCP lets client agents discover, understand and retrieve licensed Bloomberg data through a standardized MCP interface across 100M+ securities and 50,000+ fields. The important layer is not just retrieval: Bloomberg exposes semantic metadata such as field definitions, calculation context, exchange, currency, price type, period and as-of date, alongside entitlement checks, tool-level limits and reusable workflow Skills. 对 financial agents，这很像 production data access 应该长什么样：data + semantics + permissions + reusable procedures，而不是只把数据库接到 MCP。

New reportGitHub Security Lab reports 24 Android vulnerabilities found with targeted AI taskflows

Source published Sep. 28, 2026 · First seen in this briefing Sep. 29, 2026

GitHub Security Lab says its open-source Taskflow Agent helped uncover and report 24 Android vulnerabilities. The workflow breaks security work into structured steps—entry-point discovery, application classification and vulnerability-class-specific checks—rather than asking a model to audit an app in one free-form pass. GitHub also notes that models can still misjudge severity, so impact and proof-of-concept work remain human-reviewed. 这进一步说明：把 expert process 编码成 taskflow，往往比单纯给模型更长的安全 prompt 更可靠。
