AI / Coding Agents

NewGitHub adds a global default policy for Copilot Business and Enterprise features

GitHub now lets enterprise and organization admins choose a global default for eligible generally available Copilot features: Enabled, Disabled, or Let organizations decide. The policy is configurable now and takes effect Oct. 22; eligible features left Unconfigured will inherit it, while explicit enable/disable decisions are preserved and preview features remain opt-in. The scope also includes Copilot Code Review and the MCP servers in Copilot policy. 对公司级 agent governance，重点是以后“没有明确配置”的新能力也会继承一个默认策略，而不是天然保持中性状态。

NewGitHub Security Lab publishes an autonomous fuzzing Taskflow

The new C/C++ fuzzing workflow identifies entry points, creates harnesses, runs AFL++, reads coverage, iterates on harnesses and seeds, triages crashes, and writes vulnerability reports. Its architecture cleanly separates responsibilities: the LLM makes decisions, MCP tools execute primitives, and durable state lives in SQLite rather than in the model context. GitHub explicitly warns that the workflow can run LLM-chosen build commands on the host, so it should be used only inside a disposable Codespace or throwaway VM. 这是一种很具体的 “observable state + verifier + iterative operator” agent design，而不是靠一个更长的 prompt。
