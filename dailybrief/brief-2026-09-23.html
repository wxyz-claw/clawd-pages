AI / Agent Infrastructure

NewDigitalOcean opens Managed Agents to public preview

DigitalOcean now lets users run existing harnesses including Codex CLI and OpenCode in managed agent sandboxes, with persisted session state, pause/resume/fork lifecycle controls and governed access to 16,000+ tools through Action Gateway. Its docs also support driving a hosted Codex session from the local Codex CLI. 对现有 Codex Bridge / OpenCode workflow，这值得当作一个 managed-runtime benchmark：比较 isolation、permissions、resume semantics、tool gateway 和实际 active-CPU cost，而不只是模型 benchmark。Performance figures are vendor measurements, so treat them as claims to test rather than independent benchmarks.

NewGoogle Home now has an Early Access MCP server

Google’s Home MCP exposes tools for home/resource discovery, real-time device state, device actions and event history. Setup currently requires a Google Home smart-home setup, Google Home Premium Advanced, a Google Cloud project and an MCP-compatible client. Google explicitly warns that connecting a real home gives an agent device-control and home-data access; it blocks sensitive actions such as unlocking doors and recommends a separate test home when appropriate. 对 home-agent / Family Hub experiments，先拿 test structure 做 read-only/state-query experiments 会比直接连接真实家庭环境更合理。

Today / Infrastructure deadline

TodayGitHub Actions removes Node20 today

GitHub’s updated notice sets Sep. 23, 2026 as the Node20 removal date on Actions runners. The temporary ACTIONS_ALLOW_USE_UNSECURE_NODE_VERSION=true opt-out only worked until removal. If any workflow still pins an old JavaScript action, today is the useful point to inspect warnings and update the action rather than troubleshoot a later CI failure.
