AI / Coding Agents

NewGitHub Copilot app adds per-project local sandboxing

GitHub’s Sep. 23 public preview lets local Copilot sessions restrict filesystem, outbound/local network access and credentials per project. Sandboxing is off by default and applies to new sessions; an active session can use /sandbox on. Importantly, if the operating system cannot enforce the requested policy, the shell fails instead of silently running unsandboxed. 对 agent workflows，这是一项比“approval dialog”更扎实的安全边界，尤其适合测试 repo-local agent tasks。

NewChatGPT Voice can now use plugins, and Voice is available in Work

OpenAI’s Sep. 23 release notes say Voice can use the plugins and connected apps available to the account on web, iOS and Android. Voice is also available in Work on web and mobile, where it can create documents, presentations and spreadsheets, use connected apps or a browser, and hand an unfinished task back to text after the call ends. Existing permissions and usage limits still apply. 对需要边说边安排 multi-step work 的场景，这是 Voice 从“conversation layer”走向实际 workflow control 的明显变化。
