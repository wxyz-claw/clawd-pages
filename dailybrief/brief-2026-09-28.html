AI / Agent Systems

NewAgensh scales self-organized multi-agent work to 1,024 agents

Agensh removes the central orchestrator: workers gather shared context, claim subtasks, act, exchange findings, verify results and merge progress asynchronously through a shared workspace, message interface and reusable context. On the five hardest ProgramBench tasks with GPT-5.6 Sol, scaling from 1 to 128 agents raised mean final test-pass rate from 19.31% to 28.78%; on pandoc, scaling from 1 to 1,024 agents raised final test-pass rate from 33.89% to 55.06%. 这说明 agent count / organization design 本身可能是一条独立 scaling axis，而不只是 central orchestrator 的附属实现细节。

NewOpenAI prompt caching turns harness stability into a cost/latency concern

OpenAI’s current prompt-caching guide says reused cached input can receive up to a 90% discount, and exposes explicit cache breakpoints, prewarming, dashboard monitoring and cache-miss diagnostics. The implementation guidance emphasizes preserving stable conversation history and tool definitions. 对长期 MCP / agent workflows，这意味着 tool schemas、ordering 和 stable instructions 不只是代码整洁问题：频繁改变结构会直接降低 cache reuse，影响 latency 和成本。

NewAnthropic Project Swap: preference representation, not bargaining, caused most of the loss

Anthropic let Claude-powered agents barter books on behalf of 201 employees. After a short intake, agents’ inferred rankings agreed with participants’ own rankings on 61% of book pairs. In Anthropic’s decomposition, about 85% of the gap from the best achievable outcome came from imperfect preference representation, while only about 15% came from decentralized bargaining. 这给 delegation 一个很清楚的 engineering lesson：在优化 execution 之前，先单独测试 agent 是否准确压缩了 principal 的 objective。
