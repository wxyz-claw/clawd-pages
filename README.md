## Cloudflare deployment

This repository is configured as a static-only **Cloudflare Worker with Static Assets**. The repository root is the asset directory; no framework build or Worker script is required.

```bash
# Local preview
npx wrangler@latest dev

# Validate without publishing
npx wrangler@latest deploy --dry-run

# Publish to the configured workers.dev address
npx wrangler@latest deploy
```

`wrangler.jsonc` is the deployment source of truth. After the domain is active in the same Cloudflare account, attach `wangder.xyz` as a Worker Custom Domain through Cloudflare MCP or add this configuration:

```jsonc
"routes": [
  { "pattern": "wangder.xyz", "custom_domain": true }
]
```
