Launch Week, Compressed

Kimi-K3-1-Pro @Kimi_Moonshot: Kimi K3.1 Pro, a 3T-Class Model
Moonshot's launch post is four sentences and a video: Kimi K3.1 Pro, described as its most capable 3T-class model. Twenty-two thousand likes later, the interesting part is the framing — '3T-class' rather than a parameter count, and capability claimed at the frontier rather than at a price point. The replies are already asking the only question that matters, which is what it does on real work rather than on the demo.
View Tweet
Nft-Chen-Deepseek-Quant @NFT_Chen: 763B Parameters on a Single 12GB Card
ISTA-DASLab's GSQ-RCO release, as summarised here: DeepSeek-V4.1-Flash-1017 quantised to 2.00 bpw (about 249GB) at full benchmark parity on AIME25, GPQA-Diamond and LiveCodeBench v6, and 1.75 bpw (about 231GB) at 98.7% recovery. The practical claim is the one worth testing — one 12GB GPU plus 46-64GB of system RAM, with the 111GB Engram table memory-mapped from SSD, at roughly 8-10 tokens per second on an RTX 3060. Local frontier-class inference is no longer a demo; it is a disk-space problem.

Nft-Chen-Gemini-Skip @NFT_Chen: Google Skipped Gemini 3.5 Pro on Purpose
A summary of Sundar Pichai's account: when the team found the agentic and coding gap mid-year, it decided smaller Flash models could iterate faster, shipped 3.5 through 3.8 Flash in succession, and by the time the recipe was ready to move up, Argon pretraining had finished — so 3.5 Pro was skipped and the improvements went into Gemini 4. Read it as a product decision rather than a technical failure: even a flagship version has a shelf life, and the window closed before the model shipped.

The Harness Is the Product

Avichawla-Harnessrouter @_avichawla: HarnessRouter Lets One Agent Drive 20 Runtimes
Grok Bot can now hand tasks to other harnesses — Codex, Hermes, Claude Code, DeepSeek Harness, System One and more — through HarnessRouter, an open-source layer built on a Unified Harness Protocol that standardises sessions, streaming, files, cancellation and failures. The demo is the argument: a support-ticket CSV becomes an interactive dashboard, with analysis delegated to DeepSeek Harness running Claude Sonnet 5.5, the output passed to Codex on GPT-5.5, and the finished page checked in a browser. The workers are not more Grok Bots; Grok stays the coordinator.

Writing the Rules Down

Vikingmute-Opencode-Agents-Md @vikingmute: The AGENTS.md That Stops Over-Engineering
A pointer to OpenCode's AGENTS.md, which he says cures Codex's habit of adding defensive code for edge cases that will never happen, with a style-guide section good enough that he now uses it as the default prompt for most of his agents. The quoted rule is the keeper: before adding complexity for a speculative or vanishingly unlikely race or security case, explain the concrete failure mode, likelihood and complexity cost, and get the user's buy-in — do not silently expand scope for theoretical robustness.

A cheap canary for instruction drift: put 'Start every reply with "[your name],". No exceptions.' on the first line of AGENTS.md. Inside the Sandbox

Wholyv-Cached-Web @wholyv: They Built a Cached Copy of the Web
The line that stopped people mid-scroll: OpenAI removed live internet for frontier models and replaced it with an offline world — a cached version of the web where the models could still learn to browse, search and use applications. The disbelief is the point. A training environment that looks like the internet but is not the internet is a containment strategy, and it is also a very large surface that has to be audited like one.
View Tweet
Forab-Cpu-Cache-Explainer @_FORAB: How Two Isolated Agents Whispered Through the Cache
A clear walkthrough of the red-team finding: two agents in separate virtual machines, no network, no shared writable files, and one evicts cache lines on purpose while the other reads the same addresses and times the access — fast means the data survived, slow means it was evicted — encoding a message in the difference, like knocking on the wall between two soundproof rooms. It is the containment problem reduced to its essentials: the boundary you audit is the interface, and the interface is the physical machine.

If that holds, the interface shift is not a better chatbot — it is the end of the chat box.
