This thread argues that Codex, Claude Code, Cursor, and similar tools differ less by base model than by the surrounding harness: prompts, tools, hooks, context strategy, sandboxes, and observability. Hot @teach_fireworks: Long-running agents need runtime-level version control
Once agents run for hours, the bottleneck stops being code generation and becomes traceability: who changed what, via which tool call, and how to replay or recover the session. This is a strong case that execution DAGs, workspace snapshots, and audit logs are becoming core infrastructure for AI coding.
