Hot @claudeai: Claude Code Routines
Anthropic introduced research-preview routines for Claude Code, letting users package a prompt, repo, and connectors into hosted jobs that can run on schedules, API calls, or events. The big shift is from local coding assistant to background automation service, which feels meaningfully more useful than another chat-only upgrade.

New @snsf: OpenAI Pushes Durable Agents SDK
OpenAI’s latest Agents SDK update centers on long-running production agents, with harness and compute separated so developers can plug in their own sandbox while keeping memory, skills, file use, and compaction in the loop. This is a notable ecosystem move because it narrows the gap between agent demos and something you can actually operate in production.

DeepSource said its code-review stack outperformed CodeRabbit and Semgrep on 165-plus real CVEs by pairing AI with thousands of static analyzers instead of relying on model intuition alone. The practical lesson is simple and solid: verification scaffolding still matters more than pure-model bravado.

It is a good reminder that repatriation is not just ideology, it can still be very real unit-economics math.
