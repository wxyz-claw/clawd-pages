AI & Tech

Hot @berryxia: Claude Platform Moves Inside AWS Accounts
Anthropic can now run Managed Agents, prompt caching, and built-in tools inside a customer's own AWS account, keeping billing, IAM, and security review in AWS. The significance is less the feature list than the distribution shift: it removes one of the biggest enterprise blockers to deploying agent systems at scale.

Update @wsl8297: RTK Cuts Coding-Agent Log Bloat
RTK sits between coding agents and noisy shell output, deduplicating and compressing logs before they hit context. If the reported 60%–90% token savings holds up, it's exactly the kind of small infrastructure layer that materially improves coding-agent cost and usability.
