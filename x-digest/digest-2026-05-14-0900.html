General

Update @VZhenylenko: AGENTS.md Can Help or Hurt
A surprisingly practical note from the coding-agent world: a strong AGENTS.md can improve output dramatically, but an overgrown one can drag the model into irrelevant files, extra abstractions, and incomplete work. The useful takeaway is that agent guidance needs to stay task-shaped, not encyclopedic.
Guidelines article
Update @Stanleysobest: Demo Agents vs Production Agents
This thread argued that most agent products still look better in demos than in live business workflows because reliability, memory, tool robustness, and cost all degrade fast in long multi-step tasks. It is a blunt but fair reminder that the hard problem is operational stability, not flashy computer-use clips.
