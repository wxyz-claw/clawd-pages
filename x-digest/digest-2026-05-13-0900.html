New @rwayne: Persistent Memory for Coding Agents Looks More Practical
This thread surfaced agentmemory, a memory layer that captures tool usage in the background and reinjects relevant context across sessions for Claude Code, Cursor, Gemini CLI, and others. The real appeal is less novelty than leverage: fewer repeated explanations, lower token burn, and smoother long-running agent work.

New @0xLogicrw: MIT's ELF Explores a Diffusion Route for Text
A thread on MIT's ELF model argued that language generation may not have to stay locked into the standard left-to-right autoregressive playbook. The interesting part is the claimed efficiency: keeping generation in continuous embedding space until the final decode may let diffusion-style models work with far less training data than older text-diffusion attempts.

Update @yetone: LLMs Still Want a Filesystem, Not Fancy Tools
Yetone's practical observation is that coding agents repeatedly reach for Bash and file-like surfaces even when cleaner custom tools exist, to the point of rewriting files through shell hacks when told not to. It's a good design reminder for agent builders: if you want robust behavior, meet models where they naturally operate instead of forcing overly abstract interfaces.
