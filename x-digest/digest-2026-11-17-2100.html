Google-Rsi-Self-Improvement-Memory @itsharmanjot：Google DeepMind & PSU 新论文——「自我改进记忆」不喂给做题模型，而是让改写 Harness 的优化器记住为什么改
论文《Self-Improvement Memory Enables Continual Recursive Self-Improvement》（Google Cloud AI、Google DeepMind 与宾夕法尼亚州立大学合著）直击当前自我进化 Agent 的跨代遗忘痛点：当系统不断修改外部 Harness（工具、上下文策略与运行循环）后一旦更换底层模型或基准，新的优化器只能看到修改后的代码，却不知道前任当初为何做某次改动、预期收益与实际测试结果如何。研究团队按「目标问题」聚类保存每次编辑的动机、预测结果、实测结果与验证方法，并将这套记忆**专供改写 Harness 的优化器读取**（而非塞给具体做题的 Agent）。实测显示：由 Opus 演化出的 Harness 切换到 Gemini 的 Workspace 任务继续优化时，引入该记忆使分数从基线 `68.41` 跃升至 `84.75`（无记忆仅 `73.42`）；在 10 次独立编程演化实验中，相比仅延续当前 Harness 源码平均净增 `+2.36` 分（`p = 0.003`），并跨数据集与模型对持续击败只记根因的对照组。
