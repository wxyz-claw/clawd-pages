Context Engineering, Prompt Caching & Local Hardware

Prompt-Caching @ScarletKc (KC): Deep Architectural Audit of Prompt Caching in Agent Context Compaction
KC examines context compaction across Claude Code, Codex, Qwen Code, OpenCode, Cline, and pi. Modifying system prompts or dropping tool definitions during compaction breaks Anthropic's prefix cache order (tools -> system -> messages), causing massive cache misses that turn a cheap summary into a $70 re-read. The proven fix: the 'forked request' pattern preserving exact tool and system prompt bytes while requesting text-only summarization.
