Insight @runes_leo: Compress Context at Task Boundaries
This workflow tip targets a real agent failure mode: important decisions disappear when forced context compression happens in the middle of a refactor. The fix is simple and useful—make the agent decide when to compress after each task boundary instead of waiting until the context window is already full.
