PHP2Shell, Day Two

Fiveoutofnine-Wednesday-Roundup @fiveoutofnine: The Whole Day, in One Post
A running list of what broke today: two critical PHP bugs that allow code execution without a login, with details leaking before the patch, affecting WordPress, MediaWiki, Magento, Joomla and Laravel; Censys counting about 1.5 million servers on versions with no fix; the NSA, FBI, CISA, UK and CERT-EU all recommending systems be taken offline, and Japan's Prime Minister posting at 5:55 AM telling 48.8 million people to do it. The Dutch cybersecurity agency, Dutch parliament, Port of Rotterdam, Wikipedia, Asana, GOG and the University of Vienna's webmail all went down. Also in the same 24 hours: GitLab dropped a CVSS 10.0 for a bug present since 2014, LiteLLM was hijacked, Railway paused every deployment after its environment variables were accessed, TiDB Cloud disclosed a month-long intrusion with 10.6 TB claimed, and Zeabur is shutting down after a second breach in two months.

Nodejs-Security-Releases-Oct-21 @nodejs: Security Releases for 22.x, 24.x and 26.x
The official notice: new releases for Node.js 22.x, 24.x and 26.x address multiple vulnerabilities including high-severity issues. The parallel breakdown from @markgadala puts numbers on it — ten flaws patched, four rated high, the worst being CVE-2026-111497, a remote code execution bug in Node's Brotli decoder, plus two TLS issues that can make an application accept a certificate for the wrong server. Node 18 and 20 are end-of-life and did not receive fixes. If you run containers, rebuild them; a patched host binary does not patch a stale image.

Xillive-Php-Psa-For-Normal-People @XilLive: What This Means If You Are Not a Sysadmin
A security practitioner's translation of the PHP disclosure for everyone else, and the part worth keeping is the asymmetry: patching closes the hole but does not remove a backdoor or recover data already taken, and most companies do not have the staff to properly investigate whether someone got in before the fix. Practical advice — watch for breach notices and unusual logins, navigate to sites directly instead of trusting emailed reset links, expect a wave of fake security warnings, stop reusing passwords, and turn on MFA starting with email. The warning about 'your data was encrypted' is the right scepticism: encryption is not protection if the attacker controls the service holding the keys.

Supply Chain and Security Models

Socketsecurity-Litellm-Malware @SocketSecurity: LiteLLM 1.107.0 Was Compromised
LiteLLM is the Python package most LLM applications use to talk to model providers, with 92M+ monthly downloads. Version 1.107.0 shipped credential-stealing malware through PyPI wheels and Docker images, aimed at cloud credentials, developer secrets and AI tooling. Two details make it worse than a routine bad release: the Docker images were affected including latest, and the payload ran on install rather than import, so a dependency resolution was enough. Pin the version, audit lockfiles and container tags, and rotate anything that touched it.
View Tweet
Jurbed-Cloudflare-Security-Audit-Skill @jurbed: Run Cloudflare's Security Audit Skill on Everything
A concrete recommendation from a day that badly needed one: Cloudflare's security audit skill works across agent harnesses and is model independent, so it can be run over all your software with free models. The interesting claim is the stacking — use it even if a model has already audited the code, because a different pass finds different things. Given that the day's incidents were mostly unpatched dependencies and leaked credentials, an automated, repeatable audit loop is the only kind of review that keeps up.

Corridor-Argos-1-Security-Model @corridor: corridor-argos-1, a 9B Security Model
Corridor's first security model is a Qwen 3.5 9B fine-tune, and the claim is narrow on purpose: it outperforms frontier models including GPT-6 Astra and Claude Opus 5.5 on security context selection — the task of picking which code and context matters for a finding — with the lowest time to first token of the 14 models tested. A small specialised model beating frontier generalists on a scoped task is the more useful signal than the benchmark itself; security review is exactly the kind of work where latency and focus matter more than breadth.

Claude's API Gets Version Numbers

Claudedevs-Api-Version-2026-10-21 @ClaudeDevs: API Version 2026-10-21
The first official versioned release since 2023. The reasoning is the news: Anthropic plans to ship versions more often so teams can handle breaking changes on their own schedule rather than when a new model forces the issue. Version 2023-06-01 is explicitly not deprecated, so existing integrations keep working — but the implied contract change is that 'pin nothing and hope' is now a worse strategy than it was yesterday.

Small Models, Hard Proofs

Richardsocher-Flint-Local-Coding-Model @RichardSocher: Flint, a Fast Local Coding Model
Recursive's first model, built with their automated research system the Eureka Machine, and built from scratch in under four months. The specs are the pitch: best-in-class fast local coding, up to 2x faster than comparable models at 125+ tokens/sec on a MacBook Pro and 150+ on RTX Spark, open weights on Hugging Face, runnable in the usual frameworks or free on OpenCode and Pidot. 'Private, unmetered intelligence on your own machine' is the sentence that matters — it is the same promise that made LiteLLM's compromise so damaging today, minus the dependency.

Jahooma-Deepseek-Flash-Free-Unlimited @jahooma: DeepSeek Flash Free and Unlimited in 16 Countries
Limits were raised again, and DeepSeek Flash is now free and unlimited in the US, Canada, UK, Australia, New Zealand, Ireland, Norway, Sweden, Denmark, Finland, the Netherlands, Austria, Luxembourg, Iceland, Germany and Switzerland. Free frontier-adjacent inference in exactly the markets where paid subscriptions are most entrenched is a pricing attack, not a promotion — and it lands the same week Anthropic started versioning its API for stability rather than price.

Github-Chopin-Proof-Driven-Development @github: Chopin and the Proof-Driven Development Kit
GitHub Next and Microsoft Research shipped a research preview aimed at the actual bottleneck in agent-written code: review. Instead of reading diffs line by line, the PDD Kit translates developer intent into a formal specification and uses formal verification to prove the generated code meets it — stronger assurance, the post argues, than code review and tests alone. It works with Verus for Rust and integrates with Chopin. The premise is worth taking seriously: if agents write more code than humans can review, the review process has to become a checkable proof rather than a reading exercise.
