Sandboxing and Data Hygiene

Harden-369741-Sandbox-Runtime @harden_369741: Anthropic Open-Sourced Claude Code's Sandbox Runtime
A correction to the assumption that agent sandboxing means Docker or nothing: Anthropic released the runtime that Claude Code actually uses for its sandboxed bash tool, and it is neither. sandbox-runtime wraps any process at the OS level, which means the boundary is the kernel's permission model rather than a container image — cheaper to start, and auditable in a way a container is not. Worth reading before the next 'just run it in a container' architecture decision.

A short, pointed note after a run of security incidents: use Magpie's local redaction before sending anything to a model, and the recent failures would not have happened. Tvytlx-Code-Not-Video @tvytlx: 4,320 Frames, No Cuts, $187 — Because He Wrote Code Instead
The best case study of the day on choosing the right tool. He first fed the whole song to a video model; every attempt landed 1.25-2 seconds late and the full film would have cost about $480. Market and Infrastructure Reality

Balder-Capex-Off-Balance-Sheet @Balder13946731: The Bubble Risk Is in the Annuities, Not the Stock
The most substantive sceptical thread of the day, and it argues everyone is watching the wrong instrument. The heaviest capex has moved off balance sheet: Meta's Louisiana data centre is a joint venture with Blue Owl, over $20 billion, funded through private credit, funded in turn by insurers — Apollo owns Athene, KKR owns Global Atlantic — which collect annuity and life premiums. So a fixed annuity ends up backed by a building in a Louisiana cornfield, rated investment grade because the tenant is Meta. The building's residual value depends on a single tenant, the machines depreciate in five or six years against a 15-20 year lease, and annuity holders cannot exit without surrender charges. The kicker: a regulated CIO restricted to investment grade has little choice but to buy the highest-yielding paper available, which is exactly this.

Govind-Kivo-Compaction @Govind_vash02: Compaction Cut Context 33% and Cost Went Up
A rare honest negative result. He added context compaction to kivo, his terminal coding agent with a hand-written loop and no framework: pass rate stayed at 100%, peak context dropped 33%, and cost went up anyway. That is the kind of finding that only comes from instrumenting your own harness, and it is a useful counterweight to the assumption that shorter context always means cheaper runs — compaction itself costs tokens, and the break-even depends on how often you trigger it.
