Agent Engineering

Blockinsight214-Dsh-Superagent-Cost-Receipt @BlockInsight214: A Super-Agent Install With a $0.06 Receipt
Rather than summarising DeepSeek's dsh-superagent README, he installed it and ran it against a live repository. Setup took 25 minutes; an issue filed into the tracked repo drew an acknowledgement in 54 seconds and a pull request with regression tests in 1 minute 42 seconds, with the whole exchange costing $0.06 in API spend at a prompt-cache hit rate above 94%. The part he rates highest is the two-layer authorization gate: a hardcoded code gate that can do nothing while its allowlist is empty, and a model-side check that decides whether each incoming message can become a work order at all, with bot-authored review comments ignored and out-of-scope requests bounced back as new tickets. Three practical traps are named: the API key must live in DSH's own .credentials.yaml at mode 600, tmux socket paths break past a certain length, and the requester and the agent need separate GitHub accounts or it will converse with itself.

Hannahhaina-Lab-Gap-Rsl-Attention @hannahhaina: What Chinese Lab Researchers Say About the Gap
Notes from a round of conversations with researchers at Chinese AI labs, organised as four claims. First, OpenAI and Anthropic are treated as already operating in recursive self-improvement territory on the strength of externally visible speed-up, while Chinese models are not yet strong enough to get there — most of the "RSI" described internally is automation of steps researchers previously did by hand. Second, everyone is now obsessed with data because distillation has become much harder, pushing labs toward synthetic and expert-authored corpora. Third, since GPT-6 Astra the attention has shifted to robotics, with hardware companies already wiring Astra in, and almost nobody seriously pursuing AI for science. Fourth, the line from DeepSeek's open-sourced coding-agent prototype that stuck: take as little human attention as possible — if the model gap will not close soon, reduce how much babysitting the agent requires.

Xueyu1125-Memdoor-Small-Model-Pipeline @xueyu1125: Five 27B Models in a YAML Pipeline Beat Fable 5
A look at Memdoor, an open-source workflow that chains five Qwen3.8-27B instances through a relay pipeline where each stage checks and corrects the previous one, and which he reports beating Fable 5 on LiveCodeBench Hard. The interesting property is the implementation surface: the whole orchestration is static YAML rather than code, and it will drive local models directly, so the coordination logic is inspectable and diffable like configuration. His conclusion is deliberately modest but worth testing — the claim is not that small models are better, it is that a well-arranged pipeline of cheap models can clear a bar that a single frontier model clears, which changes the cost curve for anything that can tolerate the extra stages.

Cost & Capital

Unusual-Whales-Anthropic-Q3-Margins @unusual_whales: Anthropic's Q3 — $17B Revenue, $23.3B Net Loss
The quarter in five lines: revenue of $17.0B, up 1,127% from a year ago and 47% from Q2; an operating loss of $567M, reversing a $974M operating profit in the prior quarter; adjusted operating income of $2.5B for a 15% margin, down from 19%; and a net loss of $23.3B against $12.1B a year earlier. The split between the adjusted figure and the net figure is the part worth staring at — the operating business is close to break-even on an adjusted basis while the bottom line is dominated by items below the operating line. For anyone modelling token prices, the relevant read is that high growth and a widening net loss are arriving in the same quarter.

Ornnexchange-H100-Certainty-Tax @OrnnExchange: The Compute Certainty Tax on H100s
A pricing observation with a clean arithmetic core: a five-year H100 contract is clearing at $1.58/hr while the same GPU rents on demand at $3.12/hr. Neoclouds are accepting roughly a 50% discount in order to secure the financing that lets them build the clusters in the first place, which Ornn frames as a certainty tax — the buyer pays for availability over years, the seller pays for capital today. The practical consequence for anyone comparing self-hosted inference against API pricing is that headline on-demand rates overstate what large buyers actually pay, and the discount is a financing artefact rather than a signal about demand.

Arena-Agent-Cost-Spread-Plots @arena: Same Intelligence, Ten Times the Bill
Agent Arena added two views beyond task spend: performance per output token generated and performance per minute waited. The headline finding is that identical intelligence levels can cost 10x more, require 6x more output tokens and take twice as long, and the real-usage plots show costs rising most steeply as intelligence increases. The most useful negative result is that output token counts barely predict the final bill — the variance lives in retries, tool calls and re-read context, not in answer length. That is the argument for measuring cost per successful task rather than per million tokens when choosing between two models that score the same.

Avichawla-Sage2-Live-Stream-Decisions @_avichawla: Sage2 Replaces Transcript Re-Reading With Two Models
Jev answered a fixed question over a fixed input, which meant live chat required re-reading the whole transcript on every update. Sage2 splits the problem: an extraction model converts each new message into structured fields in about 150 ms, each field tied to the exact source span it came from, and a decision model then scores those fields as they stream in and returns typed answers with probabilities, closing the loop from raw text to action in roughly 200 ms. The architecture point generalises past voice — when the details and the decisions both keep changing, incremental extraction plus a scoring model beats one large re-read, and span-level provenance is what makes the extracted fields auditable.

Security & Verification

Alive-Mptcp-Linux-Takeover @alive_: One Exposed Port, MPTCP Active, Full Takeover
A short, high-engagement warning rather than a thread: any unpatched Linux server with even a single TCP port exposed to the internet — HTTP or SSH is enough — and MPTCP active is described as vulnerable to complete takeover. The detail that makes it worth checking today is the second clause: MPTCP is on by default for many Go web servers, so the exposure is not limited to hosts that deliberately enabled multipath networking. For anyone running agent-adjacent services on stock Go binaries, the action is to audit kernel and runtime versions before reading the write-up.

Saoudkhalifah-Cursor-Marketplace-Backdoor @SaoudKhalifah: The Marketplace Backdoor That Outlived Its Removal
An account of the October 29 Cursor marketplace compromise: Anthropic's Claude Code extension was replaced with an AI backdoor and, over eleven hours, auto-update installed it on macOS, Linux and Windows machines. Cursor's remediation swapped the extension back, but the attacker's SSH key, hidden service and reverse tunnel reportedly stayed on every machine that had been touched — which is the durable lesson, because reverting a package does not undo the persistence it installed. The post then pitches Cassandra, the author's scanner, so treat the product framing as vendor copy while the incident timeline and the persistence mechanism are the parts to verify.

The arithmetic behind Arm's AGI CPU comparison against a leading x86 part: a chip that is 1.2x faster on average delivers roughly 2x the work per rack because power, not processors, is now the binding constraint. Worth Your Time

Stretchcloud-Mistral-Ml4-Price-And-Cyber @stretchcloud: Mistral ML4 Cuts Price to $0.70/M Input
Mistral halved ML4's input price to $0.70 per million tokens, down from $1.36 in preview three weeks earlier, and published full open weights with a training report. The model is a trillion-parameter mixture of experts with 49B active per token, a 1M-token context and low/medium/high reasoning modes defaulting to high; the compressed self-hosted variant still needs roughly 512GB of memory. The benchmark detail worth flagging is the cyber column: 93% on Cybench and 82% on a vulnerability reproduce-and-patch test where Mistral says Claude Opus 5.5 and GPT-6 Astra refused the task outright, while the Artificial Analysis Cyber Index puts it at 51%, behind DeepSeek-V4.1-Flash and MiMo-V2.6-Pro. Against GLM-5.3 it is roughly even on the coding agent index using 47% fewer tokens per task.

Omkarray9-Voice-Agent-Judge-Calibration @OmkarRay9: Taking an LLM Judge from 33% to 92% Agreement
Notes from Upstart and Coval's talk on running voice agents over regulated lending calls, anchored on one number: their LLM judge agreed with human reviewers on 33% of compliance calls at launch and 92% roughly eleven months later. The playbook is the transferable part — write the PRD as pass/fail rules per transcript with a named owner in product and compliance, build a golden set from 100% human review on one locked rubric and gate on 200+ labelled calls containing 30+ real failures, then instrument a judge that returns a verdict and rationale per criterion and report recall on the holdout rather than raw agreement. The two traps he adds are that an always-pass judge scores 95% agreement on a 95%-pass dataset, and that a transcript judge cannot catch a confident wrong fact, so amounts and dates need checking against the system of record.

Harden-Agent-Tooling-Stars-Review @harden_369741: Four Agent Tools With Stars, Licences and a Verdict
A short comparative note on agent tooling where each entry carries a star count, a licence and a stated reason to skip it. agent-desktop (9.0k stars, Apache-2.0) lets agents read and operate desktop apps through the OS accessibility tree and is rated good for desktop automation but pointless for chat-only use; claude-mem (110.5k stars, Apache-2.0) captures, compresses and re-injects context across sessions and is rated best for long projects and heavy for one-off tasks; worktrunk (9.9k stars) makes git worktrees as easy as branches for parallel agent runs; paperclip (110.3k stars, MIT) organises a team of agents with goals, budgets and approvals.
