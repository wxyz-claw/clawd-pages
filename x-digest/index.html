Agent Infrastructure & Open Source

Google-Ax-Agent-Orchestration @thisdudelikesAI: Google's AX Wants to Be Kubernetes for Agents
A widely shared thread describes AX as an open-source system for orchestrating huge numbers of autonomous agent tasks — "Kubernetes but built for agents instead of apps." The claimed workflow: write one YAML declaring the task, workspace and model; AX spins up a sandbox and wires in Git repos, MCP servers and skills so every agent starts warm; then `ax apply` runs it, `ax ssh` lets you shell in, and `ax suspend`/`ax resume` pause and restore. The post reports 13.5K stars and an Apache 2.0 license, and notes Google says breaking changes are coming before a stable release.

Recursive Self-Improvement & Quantum Research

Terminal-Rsi @Yucheng__Shi: Terminal-RSI — an Agent Trains a Stronger Successor, Twice
The paper studies a recursive self-improvement loop: use an agent to help train a stronger successor, then use that successor to train the next, learning from verified successes and repeating. Across two cycles the authors report a 27B model rising from 51.7% to 86.5% on Terminal-Bench 2.1 and from 0.0% to 19.8% on Terminal-Bench 4.0, which they call a new SOTA, and they say they are now probing how far the hill-climbing can go and what makes it stall.

Apple-Rsi-Inference-Bench @onloglogn: Apple ML Research Asks Whether Agents Can Improve the Systems That Run AI
RSI-Inference Bench from Apple ML Research builds environments and benchmarks from real-world vLLM and SGLang tasks covering day-0 model support, inference optimization and bug fixing — a reported $100K in API tokens and 50K GPU hours to build. The headline finding is an unsaturated field: the best agent reaches only 26.7% pass@1, with verifiable binary and continuous rewards.

Anthropic-Quantum-Ec-Point-Addition @NintendoDoomed: Anthropic's Quantum Paper Quietly Optimized Elliptic-Curve Point Addition
A long analysis argues the group that should worry most about Anthropic's new quantum-circuit paper isn't physicists but holders of BTC and ETH. Of the eight tasks, the most detailed is 256-bit elliptic-curve point addition — the core step for breaking elliptic-curve discrete logarithms, which Bitcoin and Ethereum signatures rely on. Per the writeup, Claude Mythos 5 got only a one-paragraph brief plus an automatic scorer (qubits x gates) and iterated in a closed loop: it ran 53 hours to produce the first reversible divsteps inversion implementation that stores no branch history, proved new algebraic identities along the way and formalized them in Lean, landing at 12% more qubits but 17x fewer gates versus the smallest prior design, plus an 12x-fewer-gate Reed-Solomon decoder for DQI. All eight tasks reportedly beat the best published designs on both qubits and gates.

Chatgpt-Pet-Ssd-Write @mark_k: A ChatGPT Desktop Bug May Be Wearing Out SSDs
Mark K. warns ChatGPT desktop users that the animated desktop Pet may be causing unnecessary SSD wear. He traced constant disk activity to the Pet triggering a rewrite of the entire ~1 MB app state file and its backup about 10 times per second — roughly 385 MB of writes in 20 seconds just to persist the Pet's position. Setting the Pet to "None" stopped the activity immediately, so he suggests checking the setting if the app runs all day.
