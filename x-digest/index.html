Agent Engineering

Cybercommanders-Fix-Process-Not-Code @cybercommanders: Fix the Process, Not the Code
When an autonomous coding agent ships a bug, fixing the code by hand is a trap: the next session starts with a clean context window, retains no memory of your manual rescue, and will repeat the exact same class of mistake. Following a post-mortem where four specification PRs auto-merged without review and one modified the gate configuration itself, the team outlines three structural harness rules. First, protected paths fail closed mechanically at the merge gate rather than relying on prompt warnings, which decay as context grows. Second, the session that writes a change cannot certify the acceptance checklist—verification must run from an independent context against external assertions. Third, post-merge audits remain strictly decoupled from the gate to detect gate drift. You do not build a reliable fleet by being a fast janitor for autonomous commits; you build it by making bad commits impossible to land silently.

Xiangxiang103-Harnessmm-Dsh-Vs-Codex @xiangxiang103: Harness Architecture as an 80% Token Multiplier
Tsinghua and MSRA's HarnessMM paper evaluates whether outer harness design dictates how effectively reasoning-skip optimizations translate to production gains. Testing across industrial harnesses, DeepSeek Harness (DSH) on MiMo-v2.6-pro achieved 96.94% on HumanEval at 11.6k tokens per problem versus Codex's 93.88% at 62.6k (Codex burning 5.4x tokens); on MBPP, DSH hit 97.67% at 6.2k tokens versus Codex's 96.50% at 47.6k (7.7x tokens). Adding HarnessMM to skip redundant step-by-step re-reasoning on DeepSeek-flash reduced tokens by 87.93% (96.3k down to 11.6k) and lifted pass rate from 71.43% to 85.71%, while the identical modification in Codex produced 0% accuracy gain and only 29.54% token savings. The difference came down to harness cleanliness: DSH skipped 147 redundant reasoning calls across 98 problems versus Codex's 18, cutting paid model calls 954 to 415 (-56%). A clean harness allows algorithmic optimizations to be fully realized.

Kaichen-Gemini-Argon-Gpt-Tics-Audit @_kaichen: Diagnosing Frontier Model Tics with Cross-Model Audits
Using Gemini 4 Argon to scan GPT conversational sessions reveals systemic behavioral tics across modern reasoning models: reflexive defensive hedging ('cannot be considered as', 'does not represent'), premature task termination, and recursive doubt cycles (re-verifying verified verifications). Counter-prompting developed from the diagnostic suppressed these pathologies on GPT-6 Sol and Terra, though Astra's ingrained habits proved more stubborn. The useful takeaway is procedural: instead of guessing at prompt adjustments in isolation, feeding an agent's raw session logs to a competing frontier model provides an exact, unvarnished diagnostic of prompt leakage and loop failure modes.

The operational technique is simple and strict: filter with plain code first. Step one runs local grep, regex, and deduplication scripts with zero model calls to drop >99% of irrelevant volume. For multi-gigabyte logs or sprawling codebases, code-first filtering prevents token burn before reasoning begins.

Ownyourcompute-Uzu-Speculative-Decoding-M5 @OwnYourCompute: 92 Tokens/sec on Base M5 via Tree Speculative Decoding
Benchmarking Qwen3.5 9B across engines on a baseline M5 MacBook Pro: llama.cpp clocked 22.0 tok/s, MLX reached 25.1 tok/s, and Mirai's open-source uzu engine hit 92.1 tok/s. On Apple unified memory with 153 GB/s bandwidth, a 5.2 GB 4-bit model is mathematically bound to ~29 tok/s in standard autoregressive decode. uzu breaks this barrier using tree-based speculative decoding: a tiny drafter predicts 16 candidate positions structured as a tree, and the 9B model validates all branches in a single memory pass, averaging 7.5 tokens per fetch. The Rust and Metal runtime includes an OpenAI-compatible local server and Swift bindings for on-device Mac deployment.
