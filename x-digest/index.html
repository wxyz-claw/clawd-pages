Karpathy-Delete-Prompts-Keep-Graph @LunarResearcher: Karpathy — "Prompting Is Going Away. Delete Everything, Keep Graph."
A recap of a 69-minute Karpathy walkthrough arguing that graphs, not prompts, are the layer that survives: Prompts → Agents → Loops → Graphs. The distinction drawn is that a loop keeps one agent running until the job is done, while a graph decides which agents exist and what each one passes to the next. The summary's sharper line — anyone can build an agent, almost nobody builds the graph that runs them — is the reason it travelled.

Research & Benchmarks

Tencent-Hunyuan-Terminal-Rsi-27B @NFT_Chen: Hunyuan's Terminal-RSI Takes a 27B Model From 51.7% to 86.5%
A walkthrough of Tencent Hunyuan's newly open-sourced recursive self-improvement (RSI) recipe for terminal agents, Terminal-RSI. The pipeline alternates two rounds of "verified-trajectory self-rewrite" supervised fine-tuning with critique-inheriting RL refinement — Base → RSR-1 → RPR-1 → RSR-2 → RPR-2 — with each round's model generating the next round's training data. Reported results: Terminal-Bench 2.1 up from 51.70% to 86.52%, TB 4.0 from 0% to 19.84%, TB Hard at 79%, and long-horizon process reward from 0.21 to 0.37. The headline is that a 27B open model can climb to 86%+ on terminal tasks.

A timestamped guide to a two-hour course that runs from a single agent to full automation: 9:14 for your first agent, 33:11 loop engineering, 1:02:46 graph engineering, 1:30:15 agents that rewrite themselves, and 1:49:05 the full graph system. A long-form roadmap for agent engineering built as twelve stages, each pairing what to learn, what to build and why it matters. It moves from agent architecture and state machines (DAGs, LangGraph, Temporal, durable state) through raw MCP servers, computer-use and GUI automation, 3-tier memory and context engineering, multi-agent swarms with typed state handoffs, sandboxed execution (E2B, gVisor, egress blocking), inter-agent security and prompt-injection middleware, human-in-the-loop breakpoints, self-correction loops, trajectory evals as CI gates, graceful degradation, and public teardowns. The recurring argument: typed state instead of raw text, and managed memory instead of infinite context.
