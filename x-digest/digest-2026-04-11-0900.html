AI & Tech

Hot @OpenAI: New $100 Codex-Focused Tier
OpenAI said it is adding a new $100/month Pro tier with materially more Codex usage than Plus, while keeping the $200 plan as the highest-usage option and extending a temporary 2x Codex promo for existing top-tier users. The real signal is that heavy coding-agent demand is now strong enough to force explicit product segmentation instead of one-size-fits-all subscriptions.

Update @Codex_Changelog: Codex 0.120.0 Improves Agent Ops
Codex 0.120.0 adds live progress streaming for running agents, cleaner separation between live and completed hooks in the TUI, thread titles in custom status lines, and typed outputSchema support for MCP tools. It is a practical release rather than a flashy one, but exactly the kind of runtime polish that makes agent sessions easier to supervise and integrate.

New @dotey: Anthropic Managed Agents Get Safer Credential Handling
A strong explainer on Anthropic’s new Vaults model said per-user credentials can be injected for agent tool use without ever appearing inside the model context window. That matters because it is the right architectural answer to prompt-injection risk: the model can use secrets without being able to casually read or leak them.

Garry Tan open-sourced the markdown-heavy memory system behind his own agent workflow, built to recall thousands of notes, people files, meetings, and calendar entries. The broader takeaway is that production-grade agent usefulness is being won through memory architecture and retrieval discipline, not just better base models.

Update @AYi_AInotes: Ramp’s AI Adoption Playbook Is Mostly Culture

If true, that is a useful correction for teams still treating AI rollout as a procurement problem instead of a behavior-design problem.

New @GitHub_Daily: RTK Cuts Context Waste for Coding Agents

The pitch is simple but credible: if your agent keeps burning tokens on repetitive git status and test logs, better output shaping may buy more value than switching models again.
