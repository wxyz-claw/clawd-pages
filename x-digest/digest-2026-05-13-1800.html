Update @noahzweben: Claude Code Gets Separate SDK Credits
Anthropic said subscription plans will now include a separate $20-$200 monthly bucket for Agent SDK and `-p` usage, instead of drawing programmatic workflows from the same pool as interactive use. That matters because tool-driven setups like OpenClaw and other third-party agent surfaces now have a much clearer pricing boundary — and less hidden subsidy for heavy automation.

New @steipete: Computer Use Reaches Into Real Desktop Work
A Codex demo showed an agent opening the Telegram Mac app, talking to BotFather, and retrieving a needed token on its own. It’s a small task, but it captures the bigger shift: useful agent workflows are escaping the browser and starting to operate across ordinary desktop software.

Hot @landiantech: TanStack Attack Included a Destructive Trigger
Follow-up analysis of the TanStack npm compromise said the malware didn’t just steal tokens — it also installed a monitor that could reportedly run `rm -rf ~/` after a stolen GitHub token was revoked. For anyone running dev tools or agents locally, the lesson is ugly but important: back up first, then rotate credentials and inspect for persistence, because cleanup itself may trip the payload.
